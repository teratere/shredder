# 🍃 感情・ストレス吐き出しシュレッダー (Emotional Stress Shredder)

便箋に感情や愚痴を書き殴り、物理シミュレーションとWeb Audio APIの立体サウンドで跡形もなく消滅させる、シングルファイル構成のメンタルデトックスWebアプリケーションです。

> **🌐 Live Demo:**  
> ブラウザで今すぐ試せる公開版はこちら 👉 **[https://selfup.net/shredder/](https://selfup.net/shredder/)**

---

## 🌟 主な特徴・機能

### 1. 3つの選べる消滅演出 & プロシージャル音響合成
- **✂️ 本格クロスカット裁断:** 便箋が数百枚の微小ピースにスライスされ、金属ローラー刃の噛み合い音とともに下部へ引き込まれて消滅。
- **🔥 リアルお焚き上げ（焙り燃焼）:** 下端から飴色〜炭化黒焦げへと這い上がる燃焼フロント、白熱する虫食い状火線、舞い上がる黒灰と火の粉、チリチリ爆ぜるクラックルサウンド。
- **🕳️ 宇宙・特異点凝縮 ➔ 超新星爆発:** 事象の地平面へ1点に圧縮された後、一瞬の静寂を経てビッグバン大爆発と衝撃波・星屑へ昇華。

### 2. 選べる4つの科学的深呼吸ガイド（アフターケア）
感情を抹消した直後、興奮した自律神経をフラットに戻す呼吸法セレクターが起動します。
- **🌙 4-7-8呼吸法:** 4秒吸う ➔ 7秒止める ➔ 8秒吐く（急速脱力・入眠）
- **🛡️ ボックス呼吸:** 4秒吸う ➔ 4秒止める ➔ 4秒吐く ➔ 4秒止める（Navy SEALs式・冷静沈着）
- **⚡ 生理的ため息:** 3秒深く吸う ➔ 1秒吸い足す ➔ 6秒長いため息（スタンフォード大・即効リセット）
- **🍃 2:1呼吸法:** 4秒吸う ➔ 8秒吐く（息止めなし・自然なリラックス）

### 3. 完全ローカル・プライバシー保証
- `localStorage` などの端末内ストレージへの保存すら行いません。
- 抹消ボタンを押した瞬間にメモリ上の入力文字列を即時上書き破棄し、外部通信ゼロ・完全プライベートで利用できます。
